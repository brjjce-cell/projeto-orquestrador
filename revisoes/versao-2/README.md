# Rascunho recebido — versão 2

Este diretório preserva o código e os testes recebidos em 30/10/2026. **Não implantar nem executar o script na Oracle nesta versão.**

Os testes do fluxo passaram em simulação; o teste do cloud-init não foi reproduzido neste Windows. A revisão e as limitações estão em [REVISAO_V2.md](../../REVISAO_V2.md).

O fluxo remove tarefas concluídas antigas após 100 registros. O armazenamento e os testes reais com n8n, Caddy e Telegram ainda precisam de validação. Cópias históricas dos dois documentos recebidos estão em `originais/`, com aviso sobre informações não verificadas ou incorretas; elas não substituem o registro oficial.

Não incluir tokens, IDs pessoais, arquivos `.env` ou chaves privadas neste diretório.
